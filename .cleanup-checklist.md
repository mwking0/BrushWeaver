```bash
# Search for any hardcoded API keys
grep -r "AIza" . --exclude-dir={node_modules,.git,dist,build}

```

## 📝 Before First Commit

```bash
# 1. Check what will be committed
git status

# 2. Make sure .env is NOT in the list
# If it is, add it to .gitignore immediately

# 3. Review all files to be committed
git diff --cached

# 4. Commit with a good message
git commit -m "Initial commit: BrushWeaver AI-Powered Creative Studio"

# 5. Push to GitHub
git push origin main
```

## ⚠️ CRITICAL - Never Commit These

- ❌ .env files with real API keys
- ❌ node_modules/
- ❌ __pycache__/
- ❌ dist/ or build/ folders
- ❌ .vscode/ or .idea/ (IDE settings)
- ❌ Any file with "secret", "key", "token" in the name
- ❌ Database files (.db, .sqlite)
- ❌ Log files (*.log)

## 🎯 Final Check Command

```bash
# Run this before pushing
git ls-files | grep -E "\\.env$|secret|key|token|password"
# Should return nothing!
```

If you see any sensitive files, immediately:
```bash
git rm --cached <filename>
echo "<filename>" >> .gitignore
git commit -m "Remove sensitive file from tracking"
```
