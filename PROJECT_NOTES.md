# 📝 PaintWeaver - Personal Project Notes

## 🎯 Project Goals

Personal learning project to explore:
- **React Development** - Modern frontend with hooks and state management
- **FastAPI Backend** - Python web API development
- **AI Integration** - Working with Google Gemini API
- **Canvas Manipulation** - Image editing and drawing tools
- **Full-Stack Development** - Complete application from frontend to backend

## 🛠️ Tech Stack

### Frontend
- **React 18** - Component-based UI
- **Vite** - Fast development and build tool
- **Fabric.js** - Canvas manipulation library
- **CSS3** - Modern styling with custom properties

### Backend  
- **FastAPI** - Modern Python web framework
- **Google Gemini 2.5 Flash** - AI image analysis
- **PIL/Pillow** - Image processing
- **Uvicorn** - ASGI server
